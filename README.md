# MuralDigital - Aplicação para Projeto (Atividade 1)

Projeto desenvolvido para a disciplina de **Projeto Integrador Extensionista II (UNIMAR)**.

## 📌 Sobre o Projeto

O **Mural Digital** é um sistema web desenvolvido para modernizar a comunicação de uma escola, substituindo o mural físico por um espaço digital com recados, agenda, trabalhos dos alunos e informações para famílias.

## 🛠️ Requisitos e Ferramentas

- [Git](https://git-scm.com/)
- [Vite+](https://vite.plus/) (`vp`)
- [VS Code](https://code.visualstudio.com/)

## 🚀 Como Executar o Projeto

1. Clone o repositório e entre na pasta:
   git clone https://github.com/SEU-USUARIO/conectadoa.git
   cd conectadoa
2. Instale as dependências: vp install
3. Copie .env.example para .env
4. Terminal 1, inicie a API: vp run api
5. Terminal 2, inicie o frontend: vp dev
6. Abra http://localhost:5173
